    Configuration Reference¶

    Complete reference for configuring Lixy controller and agents.

    Controller Configuration¶

    The controller can be configured using a YAML configuration file, environment variables, or command-line flags.

    Configuration File¶

    Default location: ./lixy.yaml or /etc/lixy/lixy.yaml

    # Server configuration
server:
  host: "0.0.0.0"              # Server bind address
  port: 8080                    # Server port
  read_timeout: "30s"           # HTTP read timeout
  write_timeout: "30s"          # HTTP write timeout
  shutdown_timeout: "10s"       # Graceful shutdown timeout

# Database configuration
database:
  path: "/var/lib/lixy/lixy.db" # SQLite database file path
  max_open_conns: 25            # Maximum open connections
  max_idle_conns: 5             # Maximum idle connections
  conn_max_lifetime: "1h"       # Connection maximum lifetime

# Git repository configuration
git:
  repos_path: "/var/lib/lixy/repos"  # Local repository storage path
  poll_interval: "30s"               # Repository polling interval
  clone_timeout: "5m"                # Git clone timeout
  pull_timeout: "2m"                 # Git pull timeout

# Authentication configuration
auth:
  jwt_secret: "change-this-secret"   # JWT signing secret (REQUIRED)
  token_expiry: "24h"                # Default token expiration
  agent_token_expiry: "720h"         # Agent token expiration (30 days)
  refresh_token_expiry: "168h"       # Refresh token expiration (7 days)

# Logging configuration
log:
  level: "info"                      # Log level: debug, info, warn, error
  format: "json"                     # Log format: json, text
  output: "stdout"                   # Log output: stdout, stderr, file path

# CORS configuration (for web dashboard)
cors:
  enabled: true                      # Enable CORS
  allowed_origins:                   # Allowed origins
    - "http://localhost:3000"
    - "http://localhost:8080"
  allowed_methods:                   # Allowed HTTP methods
    - "GET"
    - "POST"
    - "PUT"
    - "DELETE"
  allowed_headers:                   # Allowed headers
    - "Authorization"
    - "Content-Type"
  allow_credentials: true            # Allow credentials

# Rate limiting
rate_limit:
  enabled: true                      # Enable rate limiting
  requests_per_minute: 60            # Requests per minute per IP
  burst: 10                          # Burst size

# Drift detection
drift_detection:
  enabled: true                      # Enable drift detection
  check_interval: "5m"               # Check interval
  auto_heal: true                    # Automatically fix drift
  protected_services: []             # Services to exclude from auto-heal

# Metrics and monitoring
metrics:
  enabled: true                      # Enable Prometheus metrics
  path: "/metrics"                   # Metrics endpoint path

# TLS configuration (optional)
tls:
  enabled: false                     # Enable TLS
  cert_file: "/path/to/cert.pem"    # Certificate file
  key_file: "/path/to/key.pem"      # Private key file
  auto_cert: false                   # Use Let's Encrypt auto-cert
  auto_cert_domain: ""               # Domain for auto-cert

    Environment Variables¶

    All configuration options can be set via environment variables using the LIXY_ prefix:

    # Server
export LIXY_SERVER_HOST="0.0.0.0"
export LIXY_SERVER_PORT="8080"

# Database
export LIXY_DATABASE_PATH="/var/lib/lixy/lixy.db"

# Git
export LIXY_GIT_REPOS_PATH="/var/lib/lixy/repos"
export LIXY_GIT_POLL_INTERVAL="30s"

# Authentication
export LIXY_AUTH_JWT_SECRET="your-secret-key"
export LIXY_AUTH_TOKEN_EXPIRY="24h"

# Logging
export LIXY_LOG_LEVEL="info"
export LIXY_LOG_FORMAT="json"

    Command-Line Flags¶

    lixy \
  --host 0.0.0.0 \
  --port 8080 \
  --db-path /var/lib/lixy/lixy.db \
  --log-level info \
  --log-format json

    Configuration Priority¶

    Configuration is loaded in the following order (later sources override earlier ones):

    1. Default values
    2. Configuration file
    3. Environment variables
    4. Command-line flags

    Agent Configuration¶

    The agent can be configured using a YAML configuration file or environment variables.

    Configuration File¶

    Default location: ./lixies.yaml or /etc/lixies/lixies.yaml

    # Controller connection
controller:
  url: "http://controller:8080"      # Controller URL
  token: "agt_your_token_here"       # Agent authentication token
  timeout: "30s"                     # Request timeout
  retry_interval: "10s"              # Retry interval on connection failure
  max_retries: 5                     # Maximum retry attempts

# Agent configuration
agent:
  name: "my-agent"                   # Agent name (default: hostname)
  check_interval: "10s"              # Health check interval
  deployment_timeout: "5m"           # Deployment operation timeout
  cleanup_interval: "1h"             # Cleanup interval for old containers

# LXC configuration
lxc:
  socket_path: "/var/snap/lxd/common/lxd/unix.socket"  # LXD socket path
  timeout: "30s"                     # LXC operation timeout
  image_server: "https://images.linuxcontainers.org"   # Default image server

# Container runtime
runtime:
  pull_timeout: "10m"                # Image pull timeout
  start_timeout: "2m"                # Container start timeout
  stop_timeout: "30s"                # Container stop timeout
  remove_timeout: "1m"               # Container remove timeout

# Logging
log:
  level: "info"                      # Log level: debug, info, warn, error
  format: "json"                     # Log format: json, text
  output: "stdout"                   # Log output: stdout, stderr, file path

# Resource limits (optional)
limits:
  max_deployments: 50                # Maximum concurrent deployments
  max_cpu: "4"                       # Maximum CPU cores per deployment
  max_memory: "4GB"                  # Maximum memory per deployment
  max_disk: "20GB"                   # Maximum disk per deployment

# Networking (optional)
network:
  bridge: "lxdbr0"                   # Default network bridge
  ipv4_address: "auto"               # IPv4 address allocation
  ipv6_address: "none"               # IPv6 address allocation

    Environment Variables¶

    # Controller
export LIXIES_CONTROLLER_URL="http://controller:8080"
export LIXIES_CONTROLLER_TOKEN="agt_your_token_here"

# Agent
export LIXIES_AGENT_NAME="my-agent"
export LIXIES_AGENT_CHECK_INTERVAL="10s"

# LXC
export LIXIES_LXC_SOCKET_PATH="/var/snap/lxd/common/lxd/unix.socket"

# Logging
export LIXIES_LOG_LEVEL="info"
export LIXIES_LOG_FORMAT="json"

    GitOps Repository Structure¶

    Environment Configuration¶

    Location: environments/<env-name>/config.yaml

    name: dev                            # Environment name
description: Development environment # Environment description

# Environment variables
variables:
  ENVIRONMENT: dev
  LOG_LEVEL: debug
  API_URL: https://api.dev.example.com

# Registry configuration
registry:
  url: ghcr.io                       # Registry URL
  credentials_name: github-registry  # Credential reference

# Deployments
deployments:
  - name: web-app                    # Deployment name
    target: agent1                   # Target agent
    template: web-service            # Template name
    strategy: dev-latest             # Version strategy
    variables:                       # Deployment-specific variables
      APP_VERSION: latest
      PORT: "8080"
      REPLICAS: "1"

  - name: api-service
    target: agent1
    template: api-service
    strategy: semver-minor
    variables:
      APP_VERSION: "1.2.x"
      PORT: "3000"

    Strategy Configuration¶

    Location: strategies/<strategy-name>.yaml

    name: dev-latest                     # Strategy name
description: Always use latest tag  # Strategy description
type: pattern                        # Strategy type: pattern, semver, stability

# For pattern type
pattern: "latest"                    # Tag pattern to match

# For semver type
# semver:
#   constraint: "^1.2.0"             # Semver constraint
#   prerelease: false                # Include prereleases

# For stability type
# stability:
#   level: stable                    # Stability level: stable, beta, alpha
#   max_age: "7d"                    # Maximum tag age

    Template Configuration¶

    Location: templates/<template-name>/docker-compose.yaml.gotmpl

    version: '3'
services:
  app:
    image: {{ .REGISTRY_URL }}/{{ .IMAGE_NAME }}:{{ .APP_VERSION }}
    ports:
      - "{{ .PORT }}:80"
    environment:
      - ENVIRONMENT={{ .ENVIRONMENT }}
      - LOG_LEVEL={{ .LOG_LEVEL }}
      - API_URL={{ .API_URL }}
    {{- if .REPLICAS }}
    deploy:
      replicas: {{ .REPLICAS }}
    {{- end }}
    restart: unless-stopped

    Security Configuration¶

    JWT Secret Generation¶

    Generate a secure JWT secret:

    # Using OpenSSL
openssl rand -base64 32

# Using /dev/urandom
head -c 32 /dev/urandom | base64

    TLS Configuration¶

    Self-Signed Certificate¶

    # Generate self-signed certificate
openssl req -x509 -newkey rsa:4096 \
  -keyout key.pem -out cert.pem \
  -days 365 -nodes \
  -subj "/CN=controller.example.com"

    Let's Encrypt¶

    tls:
  enabled: true
  auto_cert: true
  auto_cert_domain: "controller.example.com"

    File Permissions¶

    # Controller configuration
chmod 600 /etc/lixy/lixy.yaml
chown lixy:lixy /etc/lixy/lixy.yaml

# Agent configuration
chmod 600 /etc/lixies/lixies.yaml
chown root:root /etc/lixies/lixies.yaml

# Database
chmod 600 /var/lib/lixy/lixy.db
chown lixy:lixy /var/lib/lixy/lixy.db

    Database Optimization¶

    database:
  max_open_conns: 25                 # Increase for high load
  max_idle_conns: 5                  # Keep low to save resources
  conn_max_lifetime: "1h"            # Prevent stale connections

    Git Repository Polling¶

    git:
  poll_interval: "30s"               # Decrease for faster updates
                                     # Increase to reduce load

    Rate Limiting¶

    rate_limit:
  enabled: true
  requests_per_minute: 60            # Adjust based on expected load
  burst: 10                          # Allow burst traffic

    Monitoring Configuration¶

    Prometheus Metrics¶

    metrics:
  enabled: true
  path: "/metrics"

    Available metrics: - lixy_deployments_total - Total number of deployments - lixy_deployments_active - Currently active deployments - lixy_agents_total - Total number of agents - lixy_agents_online - Currently online agents - lixy_reconciliation_duration_seconds - Reconciliation duration - lixy_api_requests_total - Total API requests - lixy_api_request_duration_seconds - API request duration

    Logging Configuration¶

    Log Levels¶

    • debug - Detailed debugging information
    • info - General informational messages
    • warn - Warning messages
    • error - Error messages only

    Log Formats¶

    JSON Format¶

    {
  "time": "2024-11-13T10:30:00Z",
  "level": "info",
  "msg": "Deployment created",
  "deployment": "my-app",
  "target": "agent1"
}

    Text Format¶

    2024-11-13T10:30:00Z INFO Deployment created deployment=my-app target=agent1

    Log Output¶

    log:
  output: "/var/log/lixy/lixy.log"   # File path
  # or
  output: "stdout"                   # Standard output
  # or
  output: "stderr"                   # Standard error

  enabled: true

    Troubleshooting¶

    Configuration Validation¶

    # Validate controller configuration
lixy --config /etc/lixy/lixy.yaml --validate

# Validate agent configuration
lixies --config /etc/lixies/lixies.yaml --validate

    Common Issues¶

    Issue: "Invalid JWT secret" - Ensure JWT secret is at least 32 characters - Use a cryptographically secure random string

    Issue: "Database locked" - Check file permissions - Ensure only one controller instance is running - Increase max_open_conns if needed

    Issue: "Git clone timeout" - Increase clone_timeout for large repositories - Check network connectivity - Verify Git credentials
