    API Reference¶

    This document provides a comprehensive reference for the Lixy REST API.

    Base URL¶

    http://localhost:8080/api

    Authentication¶

    Most API endpoints require authentication using JWT tokens.

    Authentication Header¶

    Authorization: Bearer <your-jwt-token>

    Getting a Token¶

    POST /api/auth/login
Content-Type: application/json

{
  "username": "admin",
  "password": "your-password"
}

    Response: 

    {
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": "1",
    "username": "admin",
    "role": "admin"
  }
}

    API Endpoints¶

    Authentication¶

    Login¶

    POST /api/auth/login

    Request Body: 

    {
  "username": "string",
  "password": "string"
}

    Response: 200 OK 

    {
  "token": "string",
  "user": {
    "id": "string",
    "username": "string",
    "role": "string"
  }
}

    Change Password¶

    POST /api/auth/change-password
Authorization: Bearer <token>

    Request Body: 

    {
  "current_password": "string",
  "new_password": "string"
}

    Response: 200 OK 

    {
  "message": "Password changed successfully"
}

    Users¶

    List Users (Admin Only)¶

    GET /api/users
Authorization: Bearer <admin-token>

    Response: 200 OK 

    {
  "users": [
    {
      "id": "string",
      "username": "string",
      "role": "string",
      "created_at": "2024-01-01T00:00:00Z"
    }
  ]
}

    Create User (Admin Only)¶

    POST /api/users
Authorization: Bearer <admin-token>

    Request Body: 

    {
  "username": "string",
  "password": "string",
  "role": "admin|user"
}

    Response: 201 Created 

    {
  "id": "string",
  "username": "string",
  "role": "string"
}

    Update User (Admin Only)¶

    PUT /api/users/{id}
Authorization: Bearer <admin-token>

    Request Body: 

    {
  "username": "string",
  "role": "admin|user",
  "password": "string (optional)"
}

    Response: 200 OK

    Delete User (Admin Only)¶

    DELETE /api/users/{id}
Authorization: Bearer <admin-token>

    Response: 200 OK

    Deployments¶

    List Deployments¶

    GET /api/deployments
Authorization: Bearer <token>

    Query Parameters: - target (optional): Filter by target agent

    Response: 200 OK 

    {
  "deployments": [
    {
      "id": "string",
      "name": "string",
      "target_lxc": "string",
      "compose_yaml": "string",
      "status": "string",
      "created_at": "2024-01-01T00:00:00Z",
      "updated_at": "2024-01-01T00:00:00Z"
    }
  ]
}

    Get Deployment¶

    GET /api/deployments/{id}
Authorization: Bearer <token>

    Response: 200 OK 

    {
  "id": "string",
  "name": "string",
  "target_lxc": "string",
  "compose_yaml": "string",
  "status": "string",
  "created_at": "2024-01-01T00:00:00Z",
  "updated_at": "2024-01-01T00:00:00Z"
}

    Create Deployment¶

    POST /api/deployments
Authorization: Bearer <token>

    Request Body: 

    {
  "name": "string",
  "target_lxc": "string",
  "compose_yaml": "string"
}

    Response: 201 Created 

    {
  "id": "string",
  "name": "string",
  "target_lxc": "string",
  "status": "pending"
}

    Update Deployment¶

    PUT /api/deployments/{id}
Authorization: Bearer <token>

    Request Body: 

    {
  "compose_yaml": "string"
}

    Response: 200 OK

    Delete Deployment¶

    DELETE /api/deployments/{id}
Authorization: Bearer <token>

    Response: 200 OK

    Agents¶

    List Agents¶

    GET /api/agents
Authorization: Bearer <token>

    Response: 200 OK 

    {
  "agents": [
    {
      "id": "string",
      "name": "string",
      "ip": "string",
      "status": "online|offline",
      "last_seen": "2024-01-01T00:00:00Z",
      "metadata": {
        "version": "string",
        "os": "string"
      }
    }
  ]
}

    Register Agent¶

    POST /api/agents/register

    Request Body: 

    {
  "name": "string",
  "token": "string",
  "metadata": {
    "version": "string",
    "os": "string"
  }
}

    Response: 200 OK 

    {
  "agent_id": "string",
  "auth_token": "string"
}

    Unregister Agent¶

    DELETE /api/agents/{id}
Authorization: Bearer <token>

    Response: 200 OK

    GitOps¶

    List Repositories¶

    GET /api/gitops/repositories
Authorization: Bearer <token>

    Response: 200 OK 

    {
  "repositories": ["repo1", "repo2"],
  "count": 2
}

    Add Repository¶

    POST /api/gitops/repositories
Authorization: Bearer <token>

    Request Body: 

    {
  "name": "string",
  "url": "string",
  "branch": "string",
  "token": "string (optional)"
}

    Response: 200 OK 

    {
  "success": true,
  "message": "Repository added successfully",
  "name": "string"
}

    Remove Repository¶

    DELETE /api/gitops/repositories/{name}
Authorization: Bearer <token>

    Query Parameters: - delete_local (optional): Delete local files (default: true)

    Response: 200 OK

    Sync Repository¶

    POST /api/gitops/sync
Authorization: Bearer <token>

    Request Body: 

    {
  "repository_name": "string"
}

    Response: 200 OK 

    {
  "success": true,
  "message": "Repository synced successfully",
  "has_changes": true
}

    Reconcile Environment¶

    POST /api/gitops/reconcile-environment
Authorization: Bearer <token>

    Request Body: 

    {
  "repository_name": "string",
  "environment": "string",
  "github_token": "string (optional)"
}

    Response: 200 OK 

    {
  "success": true,
  "message": "Environment reconciled successfully",
  "environment": "string"
}

    Detect Drift¶

    POST /api/gitops/drift
Authorization: Bearer <token>

    Request Body: 

    {
  "repository_name": "string",
  "environment": "string"
}

    Response: 200 OK 

    {
  "success": true,
  "has_drift": true,
  "drifted_services": ["service1", "service2"],
  "count": 2
}

    Check for Updates¶

    POST /api/gitops/check-updates
Authorization: Bearer <token>

    Request Body: 

    {
  "repository_name": "string",
  "environment": "string",
  "github_token": "string (optional)"
}

    Response: 200 OK 

    {
  "success": true,
  "has_updates": true,
  "updates": {
    "service1": "v2.0.0",
    "service2": "v1.5.0"
  },
  "count": 2
}

    Registry Credentials¶

    List Credentials¶

    GET /api/registry/credentials
Authorization: Bearer <token>

    Response: 200 OK 

    {
  "credentials": [
    {
      "registry_type": "ghcr",
      "username": "user",
      "created_at": "2024-01-01T00:00:00Z"
    }
  ]
}

    Add Credential¶

    POST /api/registry/credentials
Authorization: Bearer <token>

    Request Body: 

    {
  "registry_type": "ghcr|dockerhub",
  "username": "string",
  "token": "string"
}

    Response: 200 OK 

    {
  "success": true,
  "message": "Credential added successfully"
}

    Delete Credential¶

    DELETE /api/registry/credentials/{registry_type}
Authorization: Bearer <token>

    Response: 200 OK

    Request Pull Token (Agent)¶

    POST /api/registry/pull-token
Authorization: Bearer <agent-token>

    Request Body: 

    {
  "registry_type": "ghcr",
  "deployment_id": "string"
}

    Response: 200 OK 

    {
  "token": "string",
  "expires_at": "2024-01-01T01:00:00Z"
}

    Health¶

    Controller Health¶

    GET /api/health

    Response: 200 OK 

    {
  "status": "healthy",
  "version": "1.0.0",
  "uptime": 3600
}

    Agent Health¶

    GET /api/agents/{id}/health
Authorization: Bearer <token>

    Response: 200 OK 

    {
  "status": "healthy",
  "last_check": "2024-01-01T00:00:00Z"
}

    Error Responses¶

    All endpoints may return the following error responses:

    400 Bad Request¶

    {
  "error": "Invalid request body"
}

    401 Unauthorized¶

    {
  "error": "Unauthorized"
}

    403 Forbidden¶

    {
  "error": "Insufficient permissions"
}

    404 Not Found¶

    {
  "error": "Resource not found"
}

    500 Internal Server Error¶

    {
  "error": "Internal server error"
}

    Rate Limiting¶

    Currently, there is no rate limiting implemented. This may be added in future versions.

    Pagination¶

    For endpoints that return lists, pagination is not currently implemented. All results are returned in a single response.

    Versioning¶

    The API is currently unversioned. Breaking changes will be communicated through release notes.

    WebSocket API (Future)¶

    Real-time updates via WebSocket are planned for future releases.

    Examples¶

    Complete Deployment Workflow¶

    # 1. Login
curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin"}'

# Save the token
TOKEN="eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."

# 2. List agents
curl http://localhost:8080/api/agents \
  -H "Authorization: Bearer $TOKEN"

# 3. Create deployment
curl -X POST http://localhost:8080/api/deployments \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "my-app",
    "target_lxc": "agent1",
    "compose_yaml": "version: \"3\"\nservices:\n  web:\n    image: nginx:latest"
  }'

# 4. List deployments
curl http://localhost:8080/api/deployments \
  -H "Authorization: Bearer $TOKEN"

    GitOps Workflow¶

    # 1. Add repository
curl -X POST http://localhost:8080/api/gitops/repositories \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "lixy-cd",
    "url": "https://github.com/user/lixy-cd.git",
    "branch": "main",
    "token": "ghp_..."
  }'

# 2. Reconcile environment
curl -X POST http://localhost:8080/api/gitops/reconcile-environment \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "repository_name": "lixy-cd",
    "environment": "dev"
  }'

# 3. Check for drift
curl -X POST http://localhost:8080/api/gitops/drift \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "repository_name": "lixy-cd",
    "environment": "dev"
  }'
