    CLI Reference¶

    Complete reference for the Lixy command-line interface.

    Overview¶

    Lixy provides two CLI tools: - lixy - Controller CLI for managing deployments, agents, and users - lixies - Agent CLI for registering and managing agents

    Global Flags¶

    These flags are available for all commands:

    --config string      Config file path (default: ./lixy.yaml)
--log-level string   Log level: debug, info, warn, error (default: info)
--log-format string  Log format: text, json (default: text)
--help, -h          Show help for command
--version, -v       Show version information

    Controller CLI (lixy)¶

    Server Commands¶

    lixy¶

    Start the Lixy controller server.

    lixy [flags]

    Flags: - --host string - Server host (default: "0.0.0.0") - --port int - Server port (default: 8080) - --db-path string - Database file path (default: "./lixy.db")

    Example: 

    # Start with default settings
lixy

# Start on custom port
lixy --port 9090

# Start with custom database
lixy --db-path /var/lib/lixy/lixy.db

    Deployment Commands¶

    lixy create deployment¶

    Create a new deployment.

    lixy create deployment NAME [flags]

    Required Flags: - --target string - Target agent name - --compose string - Path to docker-compose.yml file

    Optional Flags: - --yaml string - Inline YAML content (alternative to --compose) - --env-file string - Environment file path

    Examples: 

    # Create from file
lixy create deployment my-app \
  --target agent1 \
  --compose docker-compose.yml

# Create with inline YAML
lixy create deployment my-app \
  --target agent1 \
  --yaml 'version: "3"
services:
  web:
    image: nginx:latest'

# Create with environment file
lixy create deployment my-app \
  --target agent1 \
  --compose docker-compose.yml \
  --env-file .env

    lixy get deployments¶

    List all deployments.

    lixy get deployments [flags]

    Flags: - --target string - Filter by target agent - --status string - Filter by status (running, stopped, failed) - --output string - Output format: table, json, yaml (default: table)

    Examples: 

    # List all deployments
lixy get deployments

# List deployments on specific agent
lixy get deployments --target agent1

# List running deployments
lixy get deployments --status running

# Output as JSON
lixy get deployments --output json

    lixy get deployment¶

    Get details of a specific deployment.

    lixy get deployment NAME [flags]

    Flags: - --output string - Output format: table, json, yaml (default: table) - --verbose - Show detailed information

    Examples: 

    # Get deployment details
lixy get deployment my-app

# Get verbose output
lixy get deployment my-app --verbose

# Output as JSON
lixy get deployment my-app --output json

    lixy update deployment¶

    Update an existing deployment.

    lixy update deployment NAME [flags]

    Flags: - --compose string - Path to new docker-compose.yml - --yaml string - Inline YAML content - --env-file string - Environment file path

    Examples: 

    # Update from file
lixy update deployment my-app --compose docker-compose.yml

# Update with inline YAML
lixy update deployment my-app --yaml 'version: "3"...'

    lixy delete deployment¶

    Delete a deployment.

    lixy delete deployment NAME [flags]

    Flags: - --force - Skip confirmation prompt

    Examples: 

    # Delete with confirmation
lixy delete deployment my-app

# Force delete without confirmation
lixy delete deployment my-app --force

    lixy logs¶

    View deployment logs.

    lixy logs DEPLOYMENT [flags]

    Flags: - --follow, -f - Follow log output - --tail int - Number of lines to show (default: all) - --since string - Show logs since timestamp (e.g., "2024-01-01T00:00:00Z") - --service string - Show logs for specific service

    Examples: 

    # View all logs
lixy logs my-app

# Follow logs in real-time
lixy logs my-app --follow

# Show last 100 lines
lixy logs my-app --tail 100

# Show logs since specific time
lixy logs my-app --since "2024-11-13T10:00:00Z"

# Show logs for specific service
lixy logs my-app --service web

    Agent Commands¶

    lixy get agents¶

    List all registered agents.

    lixy get agents [flags]

    Flags: - --status string - Filter by status (online, offline) - --output string - Output format: table, json, yaml (default: table)

    Examples: 

    # List all agents
lixy get agents

# List online agents only
lixy get agents --status online

# Output as JSON
lixy get agents --output json

    lixy get agent¶

    Get details of a specific agent.

    lixy get agent NAME [flags]

    Flags: - --output string - Output format: table, json, yaml (default: table)

    Examples: 

    # Get agent details
lixy get agent agent1

# Output as JSON
lixy get agent agent1 --output json

    lixy register-agent¶

    Generate a registration token for a new agent.

    lixy register-agent NAME [flags]

    Flags: - --expires string - Token expiration duration (default: "24h")

    Examples: 

    # Generate token with default expiration
lixy register-agent agent1

# Generate token with custom expiration
lixy register-agent agent1 --expires 48h

    lixy delete agent¶

    Unregister an agent.

    lixy delete agent NAME [flags]

    Flags: - --force - Skip confirmation prompt

    Examples: 

    # Delete with confirmation
lixy delete agent agent1

# Force delete
lixy delete agent agent1 --force

    User Commands¶

    lixy create user¶

    Create a new user.

    lixy create user USERNAME [flags]

    Flags: - --password string - User password (prompted if not provided) - --role string - User role: admin, user (default: user)

    Examples: 

    # Create user with prompt for password
lixy create user developer

# Create user with password
lixy create user developer --password secret123

# Create admin user
lixy create user admin2 --role admin

    lixy get users¶

    List all users.

    lixy get users [flags]

    Flags: - --role string - Filter by role (admin, user) - --output string - Output format: table, json, yaml (default: table)

    Examples: 

    # List all users
lixy get users

# List admin users only
lixy get users --role admin

# Output as JSON
lixy get users --output json

    lixy update user¶

    Update user information.

    lixy update user USERNAME [flags]

    Flags: - --password - Change password (prompted) - --role string - Change role (admin, user)

    Examples: 

    # Change password
lixy update user developer --password

# Change role
lixy update user developer --role admin

# Change both
lixy update user developer --password --role admin

    lixy delete user¶

    Delete a user.

    lixy delete user USERNAME [flags]

    Flags: - --force - Skip confirmation prompt

    Examples: 

    # Delete with confirmation
lixy delete user developer

# Force delete
lixy delete user developer --force

    Token Commands¶

    lixy token create¶

    Create an authentication token.

    lixy token create [flags]

    Flags: - --type string - Token type: agent, user (required) - --name string - Token name/identifier (required) - --expires string - Expiration duration (default: "24h")

    Examples: 

    # Create agent token
lixy token create --type agent --name agent1

# Create user token
lixy token create --type user --name developer

# Create token with custom expiration
lixy token create --type agent --name agent1 --expires 48h

    lixy token list¶

    List all active tokens.

    lixy token list [flags]

    Flags: - --type string - Filter by type (agent, user) - --output string - Output format: table, json, yaml (default: table)

    Examples: 

    # List all tokens
lixy token list

# List agent tokens only
lixy token list --type agent

    lixy token revoke¶

    Revoke a token.

    lixy token revoke TOKEN [flags]

    Examples: 

    # Revoke a token
lixy token revoke agt_abc123...

    Registry Credential Commands¶

    lixy create registry-credential¶

    Add registry credentials.

    lixy create registry-credential NAME [flags]

    Flags: - --url string - Registry URL (required) - --username string - Registry username (required) - --token string - Registry token/password (prompted if not provided)

    Examples: 

    # Create with prompt for token
lixy create registry-credential github \
  --url ghcr.io \
  --username myuser

# Create with token
lixy create registry-credential github \
  --url ghcr.io \
  --username myuser \
  --token ghp_abc123...

    lixy get registry-credentials¶

    List registry credentials.

    lixy get registry-credentials [flags]

    Flags: - --output string - Output format: table, json, yaml (default: table)

    Examples: 

    # List all credentials
lixy get registry-credentials

# Output as JSON
lixy get registry-credentials --output json

    lixy delete registry-credential¶

    Delete registry credentials.

    lixy delete registry-credential NAME [flags]

    Flags: - --force - Skip confirmation prompt

    Examples: 

    # Delete with confirmation
lixy delete registry-credential github

# Force delete
lixy delete registry-credential github --force

    GitOps Commands¶

    lixy reconcile environment¶

    Reconcile an environment from GitOps repository.

    lixy reconcile environment NAME [flags]

    Flags: - --repository string - Repository name (required) - --force - Force reconciliation even if no changes detected

    Examples: 

    # Reconcile dev environment
lixy reconcile environment dev --repository lixy-cd

# Force reconciliation
lixy reconcile environment dev --repository lixy-cd --force

    lixy create repository¶

    Add a GitOps repository.

    lixy create repository NAME [flags]

    Flags: - --url string - Repository URL (required) - --branch string - Branch name (default: "main") - --token string - Access token for private repos - --poll-interval string - Polling interval (default: "30s")

    Examples: 

    # Add public repository
lixy create repository lixy-cd \
  --url https://github.com/user/lixy-cd.git

# Add private repository
lixy create repository lixy-cd \
  --url https://github.com/user/lixy-cd.git \
  --token ghp_abc123...

# Custom branch and poll interval
lixy create repository lixy-cd \
  --url https://github.com/user/lixy-cd.git \
  --branch develop \
  --poll-interval 60s

    lixy get repositories¶

    List GitOps repositories.

    lixy get repositories [flags]

    Flags: - --output string - Output format: table, json, yaml (default: table)

    Examples: 

    # List all repositories
lixy get repositories

# Output as JSON
lixy get repositories --output json

    lixy delete repository¶

    Remove a GitOps repository.

    lixy delete repository NAME [flags]

    Flags: - --force - Skip confirmation prompt

    Examples: 

    # Delete with confirmation
lixy delete repository lixy-cd

# Force delete
lixy delete repository lixy-cd --force

    Health Commands¶

    lixy health¶

    Check controller health.

    lixy health [flags]

    Flags: - --url string - Controller URL (default: "http://localhost:8080")

    Examples: 

    # Check local controller
lixy health

# Check remote controller
lixy health --url http://controller.example.com:8080

    Agent CLI (lixies)¶

    lixies register¶

    Register the agent with a controller.

    lixies register [flags]

    Flags: - --controller string - Controller URL (required) - --token string - Registration token (required) - --name string - Agent name (default: hostname)

    Examples: 

    # Register with auto-generated name
lixies register \
  --controller http://controller:8080 \
  --token agt_abc123...

# Register with custom name
lixies register \
  --controller http://controller:8080 \
  --token agt_abc123... \
  --name my-agent

    lixies unregister¶

    Unregister the agent from the controller.

    lixies unregister [flags]

    Examples: 

    # Unregister agent
lixies unregister

    lixies check¶

    Check agent health and connectivity.

    lixies check [flags]

    Examples: 

    # Check agent status
lixies check

    lixies¶

    Start the agent daemon.

    lixies [flags]

    Flags: - --config string - Config file path (default: ./lixies.yaml)

    Examples: 

    # Start with default config
lixies

# Start with custom config
lixies --config /etc/lixies/lixies.yaml

    Environment Variables¶

    Both CLIs support configuration via environment variables:

    # Controller
export LIXY_HOST=0.0.0.0
export LIXY_PORT=8080
export LIXY_DB_PATH=/var/lib/lixy/lixy.db
export LIXY_LOG_LEVEL=info

# Agent
export LIXIES_CONTROLLER_URL=http://controller:8080
export LIXIES_TOKEN=agt_abc123...
export LIXIES_NAME=my-agent

    Configuration Files¶

    Controller Configuration (lixy.yaml)¶

    server:
  host: "0.0.0.0"
  port: 8080

database:
  path: "/var/lib/lixy/lixy.db"

git:
  repos_path: "/var/lib/lixy/repos"
  poll_interval: "30s"

auth:
  jwt_secret: "your-secret-key"
  token_expiry: "24h"

log:
  level: "info"
  format: "json"

    Agent Configuration (lixies.yaml)¶

    controller:
  url: "http://controller:8080"
  token: "agt_abc123..."

agent:
  name: "my-agent"
  check_interval: "10s"

log:
  level: "info"
  format: "json"

    Exit Codes¶

    • 0 - Success
    • 1 - General error
    • 2 - Invalid arguments
    • 3 - Connection error
    • 4 - Authentication error
    • 5 - Not found error

    Shell Completion¶

    Generate shell completion scripts:

    # Bash
lixy completion bash > /etc/bash_completion.d/lixy

# Zsh
lixy completion zsh > "${fpath[1]}/_lixy"

# Fish
lixy completion fish > ~/.config/fish/completions/lixy.fish

    Examples¶

    Complete Workflow¶

    # 1. Start controller
lixy --port 8080

# 2. Create admin user
lixy create user admin --role admin

# 3. Generate agent token
lixy register-agent agent1

# 4. Register agent (on agent host)
lixies register \
  --controller http://controller:8080 \
  --token agt_abc123...

# 5. Add registry credentials
lixy create registry-credential github \
  --url ghcr.io \
  --username myuser

# 6. Create deployment
lixy create deployment my-app \
  --target agent1 \
  --compose docker-compose.yml

# 7. View logs
lixy logs my-app --follow
