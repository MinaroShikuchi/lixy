    Installation Guide¶

    This guide will walk you through installing and setting up Lixy on your system.

    Prerequisites¶

    Before installing Lixy, ensure you have the following:

    Required¶

    • Git - For GitOps workflows
    • LXC/LXD - On target hosts where containers will run
    • LXD 5.0 or higher recommended
    • Properly configured LXC networking

    Optional¶

    • Docker - For building and testing container images

    System Requirements¶

    Controller Host¶

    • OS: Linux (Ubuntu 20.04+, Debian 11+, or similar)
    • RAM: Minimum 512MB, recommended 1GB+
    • Disk: 1GB+ for application and data
    • Network: Accessible by all agents

    Agent Hosts¶

    • OS: Linux with LXC/LXD installed
    • RAM: Depends on container workloads
    • Disk: Sufficient for container images and data
    • Network: Can reach controller and container registries

    Installation¶

    Download Pre-built Binaries¶

    Download the latest release from GitHub Releases:

    # Download and extract (example for Linux amd64)
wget https://github.com/MinaroShikuchi/lixy/releases/download/v1.0.0/lixy-linux-amd64.tar.gz
tar -xzf lixy-linux-amd64.tar.gz

# Install binaries
sudo mv lixy /usr/local/bin/
sudo mv lixies /usr/local/bin/

# Make them executable
sudo chmod +x /usr/local/bin/lixy
sudo chmod +x /usr/local/bin/lixies

# Verify installation
lixy version
lixies version

    Available architectures: - lixy-linux-amd64.tar.gz - Linux 64-bit (Intel/AMD) - lixy-linux-arm64.tar.gz - Linux ARM 64-bit (Raspberry Pi, etc.) - lixy-darwin-amd64.tar.gz - macOS Intel - lixy-darwin-arm64.tar.gz - macOS Apple Silicon

    Note: If you want to build from source for development purposes, see the Contributing Guide.

    LXC/LXD Setup¶

    Installing LXD¶

    Ubuntu/Debian¶

    sudo snap install lxd
sudo lxd init

    Other Linux Distributions¶

    Follow the official LXD installation guide.

    Configuring LXD¶

    Run the initialization wizard:

    sudo lxd init

    Recommended settings: - Storage backend: dir or zfs - Network bridge: yes (creates lxdbr0) - IPv4 address: Auto - IPv6 address: Auto or none - LXD available over network: no (unless needed)

    Verify LXD Installation¶

    # Check LXD version
lxd --version

# List containers (should be empty initially)
lxc list

# Test by launching a container
lxc launch ubuntu:22.04 test-container
lxc list
lxc delete test-container --force

    Controller Setup¶

    1. Create Configuration Directory¶

    sudo mkdir -p /etc/lixy
sudo mkdir -p /var/lib/lixy

    2. Create Configuration File¶

    Create /etc/lixy/lixy.yaml:

    # Controller configuration
server:
  host: "0.0.0.0"
  port: 8080

# Database configuration
database:
  path: "/var/lib/lixy/lixy.db"

# Git repository configuration
git:
  repos_path: "/var/lib/lixy/repos"
  poll_interval: "30s"

# Authentication
auth:
  jwt_secret: "change-this-to-a-secure-random-string"
  token_expiry: "24h"

# Logging
log:
  level: "info"
  format: "json"

    3. Generate JWT Secret¶

    # Generate a secure random string for JWT secret
openssl rand -base64 32

    Update the jwt_secret in your configuration file with this value.

    4. Set Permissions¶

    sudo chown -R $USER:$USER /var/lib/lixy
sudo chmod 700 /etc/lixy
sudo chmod 600 /etc/lixy/lixy.yaml

    5. Start the Controller¶

    # Run in foreground
lixy

# Or run as a service (see systemd section below)

    The controller will: - Start the HTTP server on port 8080 - Initialize the database - Create the default admin user (username: admin, password: admin) - Begin monitoring Git repositories

    6. Verify Controller is Running¶

    # Check health endpoint
curl http://localhost:8080/health

# Expected response:
# {"status":"healthy"}

    Agent Setup¶

    1. Ensure LXD is Running¶

    sudo systemctl status snap.lxd.daemon

    2. Get Registration Token¶

    On the controller, generate a registration token:

    lixy token create --type agent --name "my-agent"

    This outputs a token like: agt_abc123...

    3. Register the Agent¶

    On the agent host:

    lixies register \
  --controller http://controller-host:8080 \
  --token agt_abc123... \
  --name my-agent

    The agent will: - Connect to the controller - Register itself - Start listening for deployment commands

    4. Verify Agent Registration¶

    On the controller:

    lixy get agents

# Expected output:
# NAME       STATUS    LAST_SEEN
# my-agent   online    2024-11-13 10:30:00

    Running as a System Service¶

    Controller Service (systemd)¶

    Create /etc/systemd/system/lixy.service:

    [Unit]
Description=Lixy Controller
After=network.target

[Service]
Type=simple
User=lixy
Group=lixy
WorkingDirectory=/var/lib/lixy
ExecStart=/usr/local/bin/lixy
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target

    Enable and start:

    sudo systemctl daemon-reload
sudo systemctl enable lixy
sudo systemctl start lixy
sudo systemctl status lixy

    Agent Service (systemd)¶

    Create /etc/systemd/system/lixies.service:

    [Unit]
Description=Lixy Agent
After=network.target snap.lxd.daemon.service
Requires=snap.lxd.daemon.service

[Service]
Type=simple
User=root
Group=root
ExecStart=/usr/local/bin/lixies
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target

    Enable and start:

    sudo systemctl daemon-reload
sudo systemctl enable lixies
sudo systemctl start lixies
sudo systemctl status lixies

    Web Dashboard Setup¶

    The web dashboard is included with the controller and accessible at:

    http://controller-host:8080/

    Default Credentials¶

    • Username: admin
    • Password: admin

    ⚠️ IMPORTANT: Change the default password immediately after first login!

    Changing Admin Password¶

    lixy user update admin --password
# Enter new password when prompted

    Firewall Configuration¶

    Controller Host¶

    Allow incoming connections on port 8080:

    # UFW
sudo ufw allow 8080/tcp

# iptables
sudo iptables -A INPUT -p tcp --dport 8080 -j ACCEPT

    Agent Hosts¶

    Agents need outbound access to: - Controller (port 8080) - Container registries (port 443)

    No inbound ports need to be opened.

    Verification¶

    1. Check Controller Health¶

    curl http://localhost:8080/health

    2. List Registered Agents¶

    lixy get agents

    3. Create a Test Deployment¶

    # Create a simple docker-compose.yml
cat > test-compose.yml <<EOF
version: '3'
services:
  nginx:
    image: nginx:latest
    ports:
      - "8080:80"
EOF

# Deploy it
lixy create deployment test-app \
  --target my-agent \
  --compose test-compose.yml

# Check deployment status
lixy get deployments

    4. Access Web Dashboard¶

    Open your browser and navigate to: 

    http://controller-host:8080/

    Login with the default credentials and verify you can see: - Dashboard overview - Registered agents - Deployments list

    Troubleshooting¶

    Controller Won't Start¶

    Check logs: 

    # If running as service
sudo journalctl -u lixy -f

# If running in foreground
# Logs are printed to stdout

    Common issues: - Port 8080 already in use - Database file permissions - Invalid configuration file

    Agent Won't Register¶

    Check connectivity: 

    # Test connection to controller
curl http://controller-host:8080/health

    Common issues: - Firewall blocking port 8080 - Incorrect controller URL - Invalid registration token - LXD not running

    LXD Permission Issues¶

    If you get permission errors:

    # Add user to lxd group
sudo usermod -a -G lxd $USER

# Logout and login again for group changes to take effect

    Database Locked Errors¶

    If you see "database is locked" errors:

    # Stop the controller
sudo systemctl stop lixy

# Check for stale lock files
ls -la /var/lib/lixy/

# Remove lock files if present
sudo rm /var/lib/lixy/lixy.db-shm
sudo rm /var/lib/lixy/lixy.db-wal

# Restart controller
sudo systemctl start lixy

    Upgrading¶

    Backup First¶

    # Backup database
sudo cp /var/lib/lixy/lixy.db /var/lib/lixy/lixy.db.backup

# Backup configuration
sudo cp /etc/lixy/lixy.yaml /etc/lixy/lixy.yaml.backup

    Upgrade Process¶

    # Stop services
sudo systemctl stop lixy
sudo systemctl stop lixies

# Download new binaries
wget https://github.com/MinaroShikuchi/lixy/releases/download/v1.1.0/lixy-linux-amd64.tar.gz
tar -xzf lixy-linux-amd64.tar.gz

# Replace old binaries
sudo mv lixy /usr/local/bin/
sudo mv lixies /usr/local/bin/
sudo chmod +x /usr/local/bin/lixy
sudo chmod +x /usr/local/bin/lixies

# Restart services
sudo systemctl start lixy
sudo systemctl start lixies

# Verify
lixy version
lixies version

    Uninstallation¶

    Stop Services¶

    sudo systemctl stop lixy
sudo systemctl stop lixies
sudo systemctl disable lixy
sudo systemctl disable lixies

    Remove Binaries¶

    sudo rm /usr/local/bin/lixy
sudo rm /usr/local/bin/lixies

    Remove Data (Optional)¶

    sudo rm -rf /var/lib/lixy
sudo rm -rf /etc/lixy

    Remove Service Files¶

    sudo rm /etc/systemd/system/lixy.service
sudo rm /etc/systemd/system/lixies.service
sudo systemctl daemon-reload

    Need help? Check our troubleshooting guide or open an issue.
