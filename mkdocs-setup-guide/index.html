    MkDocs Setup Guide for Lixy Documentation¶

    This guide will help you set up MkDocs to create a professional documentation site for Lixy.

    Overview¶

    MkDocs is a fast, simple static site generator that's geared towards building project documentation. It will transform your existing Markdown documentation into a beautiful, searchable website.

    Installation¶

    Prerequisites¶

    • Python 3.7 or higher
    • pip (Python package manager)

    Install MkDocs¶

    # Install MkDocs
pip install mkdocs

# Install Material theme (recommended)
pip install mkdocs-material

# Install useful plugins
pip install mkdocs-mermaid2-plugin
pip install mkdocs-git-revision-date-localized-plugin
pip install mkdocs-minify-plugin

    Configuration File¶

    Create a file named mkdocs.yml in the root of your project with the following content:

    # MkDocs Configuration for Lixy Documentation
site_name: Lixy Documentation
site_description: GitOps deployment platform for LXC containers
site_author: Lixy Team
site_url: https://MinaroShikuchi.github.io/lixy  # Update with your actual URL

# Repository
repo_name: lixy
repo_url: https://github.com/MinaroShikuchi/lixy  # Update with your actual repo
edit_uri: edit/main/docs/

# Copyright

    Building the Documentation¶

    Local Development¶

    # Serve documentation locally with live reload
mkdocs serve

# The site will be available at http://127.0.0.1:8000

    Build Static Site¶

    # Build the static site
mkdocs build

# Output will be in the 'site/' directory

    Deploy to GitHub Pages¶

    # Deploy to GitHub Pages (creates/updates gh-pages branch)
mkdocs gh-deploy

# Your docs will be available at:
# https://MinaroShikuchi.github.io/lixy

    GitHub Actions Workflow¶

    Create .github/workflows/docs.yml for automatic deployment:

    name: Deploy Documentation

on:
  push:
    branches:
      - main
    paths:
      - 'docs/**'
      - 'mkdocs.yml'
  workflow_dispatch:

permissions:
  contents: write

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: 3.x

      - name: Install dependencies
        run: |
          pip install mkdocs-material
          pip install mkdocs-mermaid2-plugin
          pip install mkdocs-git-revision-date-localized-plugin
          pip install mkdocs-minify-plugin

      - name: Deploy documentation
        run: mkdocs gh-deploy --force

    ReadTheDocs Setup¶

    If you prefer ReadTheDocs over GitHub Pages:

    1. Create .readthedocs.yml in project root:
    version: 2

build:
  os: ubuntu-22.04
  tools:
    python: "3.11"

mkdocs:
  configuration: mkdocs.yml
  fail_on_warning: false

python:
  install:
    - requirements: docs/requirements.txt
    1. Create docs/requirements.txt:
    mkdocs>=1.5.0
mkdocs-material>=9.4.0
mkdocs-mermaid2-plugin>=1.1.0
mkdocs-git-revision-date-localized-plugin>=1.2.0
mkdocs-minify-plugin>=0.7.0
    1. Import project on ReadTheDocs:
    2. Go to https://readthedocs.org
    3. Import your GitHub repository
    4. The documentation will build automatically

Lixy provides a modern, declarative approach to managing LXC container deployments using GitOps principles.

    Benefits of MkDocs¶

    ✅ Professional appearance - Material theme looks great
    ✅ Search functionality - Built-in search across all docs
    ✅ Mobile responsive - Works on all devices
    ✅ Version control - Docs live with code
    ✅ Easy navigation - Sidebar and tabs
    ✅ Code highlighting - Syntax highlighting for all languages
    ✅ Mermaid diagrams - Your existing diagrams will render beautifully
    ✅ Dark mode - Automatic theme switching
    ✅ Git integration - Shows last updated dates
