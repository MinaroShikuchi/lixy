    GitHub Authentication Methods¶

    Lixy supports two GitHub authentication methods:

    1. GitHub App (Server-to-Server) - Recommended for registry access (NO user interaction)
    2. GitHub OAuth - For user authentication (requires user interaction)

    GitHub App Authentication (Recommended for GHCR)¶

    Use this for: Automated container registry access without user interaction

    The system uses secure encrypted storage for GitHub App credentials (App ID and Private Key PEM).

    Quick Start¶

    See the comprehensive GitHub App Setup Guide for detailed instructions.

    Configuration¶

    GitHub App Setup¶

    1. Create a GitHub App in your organization/account settings
    2. Download the private key (PEM file)
    3. Note the Client ID (App ID)

    API Usage¶

    Configure GitHub App¶

    curl -X POST \
  -H "Authorization: Bearer your-token" \
  -H "Content-Type: application/json" \
  -d '{
    "client_id": "123456",
    "private_key": "-----BEGIN RSA PRIVATE KEY-----\n...\n-----END RSA PRIVATE KEY-----"
  }' \
  http://localhost:8080/api/github/config

    Check Configuration Status¶

    curl -H "Authorization: Bearer your-token" \
     http://localhost:8080/api/github/config

    Response: 

    {
  "client_id_configured": true,
  "private_key_configured": true,
  "redirect_uri": "http://localhost:8080/github/callback",
  "auth_url": "/github/auth",
  "callback_url": "/github/callback"
}

    GitHub App vs OAuth¶

    GitHub App (Server-to-Server) ✅ Recommended for GHCR¶

    Use for: Container registry access, automated deployments

    Advantages: - ✅ No user interaction required - fully automated - ✅ Uses App ID + Private Key (PEM) - ✅ More secure and flexible - ✅ Short-lived tokens (1 hour, auto-refreshed) - ✅ Can act on behalf of the app - ✅ Better permissions model - ✅ Fine-grained repository access

    Authentication Flow: 1. Configure App ID + Private Key via /api/github/config 2. Controller generates JWT using private key 3. Controller requests installation access token from GitHub API 4. Token used to authenticate with GHCR (ghcr.io) 5. Tokens automatically refreshed every hour

    Setup: See GitHub App Setup Guide

    OAuth App (User Authentication) ⚠️ Requires User Interaction¶

    Use for: User login, personal access

    Characteristics: - ⚠️ Requires user interaction - user must click "Authorize" - Uses Client ID + Client Secret - Simpler but less flexible - Only user-level permissions - Requires OAuth callback flow

    Authentication Flow: 1. Configure app credentials via /api/github/config 2. Start OAuth flow: Redirect user to /github/auth 3. User clicks "Authorize" on GitHub 4. Handle callback: GitHub redirects to /github/callback 5. Exchange code for access token 6. User authenticated with GitHub

    Security Features¶

    • AES-GCM Encryption: Private keys encrypted at rest
    • PEM Key Storage: Secure storage of RSA private keys
    • JWT Signing: Proper GitHub App authentication
    • No plaintext storage: Keys never stored in plaintext

    Example Frontend Integration¶

    // Configure GitHub App
const configureGitHub = async (clientId, privateKey) => {
  const response = await fetch('/api/github/config', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${token}`,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      client_id: clientId,
      private_key: privateKey // PEM format
    })
  });
  return response.json();
};

    Private Key Format¶

    The private key should be in PEM format: 

    -----BEGIN RSA PRIVATE KEY-----
MIIEpAIBAAKCAQEA...
...rest of key...
-----END RSA PRIVATE KEY-----

    Which Method Should I Use?¶

    For Container Registry Access (GHCR)¶

    Use GitHub App (Server-to-Server) - No user interaction needed - Automated token generation - Perfect for CI/CD and deployments - See: GitHub App Setup Guide

    For User Authentication¶

    Use OAuth App - User login to dashboard - Personal access to repositories - Requires user to authorize

    Migration from OAuth to GitHub App¶

    If you're currently using OAuth for registry access, migrate to GitHub App:

    1. Create a GitHub App (see setup guide)
    2. Configure App ID and Private Key
    3. Install the app on your organization
    4. Update deployments to use ghcr registry type
    5. Tokens will be automatically generated without user interaction
